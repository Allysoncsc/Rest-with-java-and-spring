# Título do projeto

### 📋 Descrição

Módulo: 275- BOTAO DE AÇAO ATIVAR/INATIVAR PRODUTOS COMEX<br/>

Botões estão na TGFCAB são usados pelo setor COMEX para setar campos na TGFVOA.



## ⚙️ Funcionalidades


1. Botão 345-ATIVAR PRODUTOS COMEX:<br/>
    - UPDATE TGFVOA SET UNIDTRIB = 'S', ATIVO = 'S', DESCRUNTRIBEXPORT = 'KG' WHERE CODPROD=:CODPROD AND CODVOL = 'KG'
2. Botão 346-INATIVAR PRODUTOS COMEX:<br/>
    - UPDATE TGFVOA SET UNIDTRIB = 'N', ATIVO = 'N', DESCRUNTRIBEXPORT =NULL WHERE CODPROD=:CODPROD AND CODVOL = 'KG'
